OCI API 设置（支持多个账号）

切换下拉即切换当前使用的甲骨文账号；编辑已有凭证时私钥留空 = 保持不变。

填写 Oracle Cloud API 密钥信息（租户 OCID、用户 OCID、指纹、私钥、区域、分区）。凭证仅保存在服务器本地文件中，不会上传到任何地方。

如何获取这些凭证？（点击展开）
  1. 登录 OCI 控制台 → 右上角头像 → Tenancy: xxx，复制「租户 OCID」。
  2. 头像 → 我的资料 → 左侧 API 密钥 → 添加 API 密钥（生成密钥对并下载私钥）→ 复制「指纹 Fingerprint」。
  3. 我的资料 → 用户信息 → 复制「用户 OCID」。
  4. 把下载的私钥文件内容（-----BEGIN PRIVATE KEY----- 整段）粘贴到下方「私钥内容」，或填写私钥文件完整路径。
  5. 区域填例如 ap-singapore-1。分区选根分区或你的 compartment。
